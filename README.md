# Adaptive Temporal Segmentation of Speech: A Controlled Characterization on WavLM and Mel Features

This repository contains the code, data, and analysis for the paper "Adaptive Temporal Segmentation of Speech: A Controlled Characterization on WavLM and Mel Features."

## Paper

The final paper is available as `paper.md`. A PDF version can be generated from the markdown file.

## Repository Structure

```
.
├── paper.md                          # Final paper (camera-ready)
├── experiments/                      # Experiment scripts and results
│   ├── experiment_*.py              # Main experiment scripts (A-F)
│   ├── results_experiment_*.json    # Saved results for each experiment
│   ├── analyze_*.py                 # Analysis scripts
│   ├── analysis_*.json             # Analysis outputs
│   ├── make_figures.py              # Figure generation script
│   └── *.log                       # Run logs
├── figures/                         # Generated figures
│   ├── fig1_rd_crossover.png       # RD crossover plot
│   └── fig2_timing_ablation.png    # Timing ablation plot
└── docs/                            # Experiment documentation and notes
```

## Experiments

The paper reports the following experiments:

- **Experiment A:** Mechanism validation on synthetic signals
- **Experiment B:** Rate-distortion on real speech (continuous)
- **Experiment B2:** Quantized rate-distortion
- **Experiment C:** Structure analysis
- **Experiment D:** Boundary interpretation (drift analysis)
- **Experiment E:** Information organization
- **Experiment F:** Mel feature analysis
- **Matched-rate multi-seed:** Comprehensive RD comparison (3 seeds)
- **Run-length control:** Variable-rate frame baseline

## Results

All result JSON files are in the `experiments/` directory with the naming convention `results_experiment_<name>.json`. These files contain:
- Per-seed metrics
- Summary statistics
- Configuration details

## Re-running Experiments

To re-run experiments, you will need:

1. The Nepali FastSpeech2 dataset (see paper for details)
2. Pre-trained WavLM model
3. Python environment with required dependencies (torch, numpy, scipy, sklearn, etc.)

Each experiment script can be run directly:
```bash
python experiments/experiment_a.py
python experiments/experiment_b.py
# etc.
```

## Figures

Figures are generated by `experiments/make_figures.py` from the saved result JSON files. The figures are saved in the `figures/` directory.
